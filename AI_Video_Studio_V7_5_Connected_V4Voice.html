Giao việc cho quản lý

Kế hoạch chưa thực thi. Khi nhận việc, quản lý Kilo có thể bổ sung nhiệm vụ.

Cài Kilo và bật cầu nối
  1. Cài VS Code và extension Kilo Code, mở thư mục dự án này.
  2. Đăng nhập Kilo hoặc kết nối provider, chọn model. Chọn agent ai-manager để giao việc trực tiếp trong IDE.
  3. Để nhận yêu cầu từ web, cài Node.js LTS và CLI trong terminal:
    npm install -g @kilocode/cli
kilo auth login
  4. Giữ web đang chạy. Mở terminal thứ hai ở thư mục dự án:
    python tools/company_worker.py
    Nếu dùng Windows venv: .venv\Scripts\python.exe tools\company_worker.py

Worker dùng model đã cấu hình riêng trong Kilo. API key của web không tự đăng nhập Kilo. Chi tiết: docs/AI_COMPANY_VI.md.
